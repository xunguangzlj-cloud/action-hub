# 行动中枢

面向个人的工作资料与行动管理工具：先记录，再整理，最后行动。支持 Windows 浏览器与安卓；数据先保存在本机，配置自己的国内云服务后可跨设备同步。

## 下载与阅读

当前版本：**1.1.1**（安卓版本号 111），2026-09-03。

- [下载发布包或单独的 APK](https://github.com/xunguangzlj-cloud/action-hub/releases/tag/v1.1.1)
- [完整使用说明](使用说明.md)
- [本次发布说明](发布说明.md)

下载 ZIP 后先解压。`使用说明.html` 可直接用电脑或手机浏览器打开，离线阅读，无需登录或外部字体。

## 开始使用

1. 手机打开 `行动中枢-Android-1.1.1.apk` 安装。旧用户先备份，直接覆盖更新，不要先卸载。
2. 进入收集箱，在“一句话记录”中输入事情，点击“记录”。
3. 点击条目的“整理”，移动到合适文件夹；要执行的事项放入行动计划，自定优先级、日期和提醒。
4. 换设备时，先在更新端点“数据 → 立即同步”，成功后再在另一端点一次。

## 主要功能

- 收集箱中的文件位置登记：只记录文件名、类型与位置，不上传原文件。
- 独立的“一句话记录”固定文件夹，等待手动整理。
- 行动计划的收集、明确、行动文件夹与每周回顾。
- 图标文件夹、层级分类、搜索定位、自定优先级与置顶。
- 今日行动、时间筛选、完成记录与批量删除。
- 本机保存、JSON 备份、可配置的国内云同步。

## 使用边界

本仓库用于发布安装包和说明，不提供共享的公共云账户，不附个人密钥、个人记录或开发证书。新用户需要自行准备同步服务；现有用户沿用自己的配置。电脑网页版使用部署者提供的工作台网址，本仓库不是已经部署的工作台。

数据同步不是实时推送，不等于程序更新，也不能代替备份。通知受系统权限和后台限制影响，重要时间点请保留系统闹钟或日历提醒。

目前不含 AI 自动规划、聊天软件自动读取、录音和自动生成今日建议。
