# 行动中枢 / Action Hub

## 中文

行动中枢是一款本地优先的个人工作记录与行动管理工具，支持 Windows 网页、安卓安装版和 iPhone 网页应用。断网时可以使用，修改会自动保存；跨设备自动同步需要连接自己的 uniCloud 服务。

- [English quick start](QUICK_START_EN.md)

当前版本：1.1.6。支持自动或自定义提醒、仅设日期时的 08:00/12:00/18:00/22:00 默认提醒、安卓系统通知铃声、系统日历、任务持续自动保存，以及切后台或息屏时立即尝试云同步。

安卓请下载 APK 并覆盖安装旧版，不要先卸载。已有同步服务无需重新部署云函数，也不要更换同步密钥。

浏览器和 iPhone 网页应用完全关闭后不能保证准时提醒；重要事项建议加入系统日历。本应用不收软件订阅费，网盘按钮只用于手动备份，不会自动合并设备数据。

## English

Action Hub is a local-first personal work capture and action-management tool for Windows browsers, Android, and iPhone web apps. It works offline and saves edits automatically. Cross-device synchronization is available through your own uniCloud service.

- [Download the latest release](https://github.com/xunguangzlj-cloud/action-hub/releases/latest)
- [English quick start](QUICK_START_EN.md)
- [English user guide](USER_GUIDE_EN.md)
- [中文极简说明](极简版说明.md)
- [中文详细说明](详细版说明.md)

Current version: 1.1.6. It adds automatic and custom reminders, default reminders at 08:00, 12:00, 18:00, and 22:00 for date-only tasks, Android system notifications with sound, system-calendar integration, continuous form autosave, and immediate sync attempts when the app goes to the background or the screen turns off.

On Android, install the new APK over the existing app. Do not uninstall the old version first. Existing sync users do not need to redeploy the cloud function or change their sync key.

Browsers and iPhone web apps cannot guarantee reminders after the app is fully closed. Add important tasks to the system calendar. The app itself has no software subscription fee. Cloud-drive buttons create manual backups; they do not merge data automatically.
