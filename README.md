# 行动中枢

个人工作记录工具，支持电脑网页、安卓安装版和 iPhone 网页应用。本机离线可用，修改会自动保存；跨设备同步需要连接自己的同步服务。

- [下载最新版](https://github.com/xunguangzlj-cloud/action-hub/releases/latest)
- [极简版说明：开始使用与同步](极简版说明.md)
- [详细版说明：安装、提醒、同步、备份与排错](详细版说明.md)

当前版本：1.1.6。新增按计划开始时间提醒、仅设日期时的 08:00/12:00/18:00/22:00 默认提醒、自定义多个提醒时间、安卓系统通知铃声，以及加入系统日历入口。编辑任务时会持续自动保存，切到后台、息屏或关闭前会立即尝试上传云端；若上传过程中又有修改，会保留新修改并继续补传。

安卓请下载 APK 并覆盖安装，不要先卸载旧版。`web` 为电脑和 iPhone 使用的网页文件；`uniCloud-aliyun` 为可选同步服务模板。已有同步服务无需重新部署云函数，也不要更换同步密钥。

浏览器和 iPhone 网页应用受系统限制，不能保证在应用完全关闭后准时发出强提醒；重要事项建议用“加入系统日历”。安卓安装版需要允许通知和铃声，并避免被系统省电策略完全限制后台运行。

应用不收订阅费。网盘按钮用于手动保存备份，不会自动合并两台设备的数据。具体任务管理方式可在应用内自由探索。
