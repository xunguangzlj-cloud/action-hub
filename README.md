# 行动中枢

个人工作记录工具，支持电脑网页、安卓安装版和 iPhone 网页应用。本机自动保存，可离线使用；跨设备自动同步需要连接自己的同步服务。

- [下载最新版](https://github.com/xunguangzlj-cloud/action-hub/releases/latest)
- [极简版说明：开始使用与同步](极简版说明.md)
- [详细版说明：安装、同步配置、备份、换机与排错](详细版说明.md)

当前版本：1.1.3。修复手机保存后立即切到后台或息屏时，修改可能未上传的问题；恢复前台后会自动补传仍未同步的内容。应用不收订阅费，网盘和云服务的套餐费用由各服务提供方决定。

下载中的 APK 用于安卓；`web` 为电脑和 iPhone 使用的网页文件；`uniCloud-aliyun` 为可选同步服务模板。GitHub 仓库与 ZIP 下载链接不是工作台网址。

网盘按钮用于保存备份，不会自动合并两台设备的数据。具体任务管理方式请在应用内自由探索。
